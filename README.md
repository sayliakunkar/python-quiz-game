# Python Quiz Game

## About
This is a simple quiz game built using Python. It asks multiple-choice questions and checks the user's answers.

## Features
- Multiple-choice questions
- Checks correct and incorrect answers
- Calculates the final score
- Displays the correct answer for wrong responses

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Run the Python file:

```bash
python quiz_game.py
```

4. Enter your answers using `a`, `b`, `c`, or `d`.

## Example
The game displays questions, checks your answers, and shows your final score at the end.
